# 游戏版型与快速输入整合设计

## 概述

整合游戏版型选择功能与快速输入优化功能，实现：
- 版型决定可标记角色与发言模板
- 动态玩家布局（12-15人）
- 发言模板快速输入
- 玩家卡片快捷入口

---

## 一、人数范围与动态布局

### 1. 基础规则

| 维度 | 规则 |
|------|------|
| 默认人数 | 12人 |
| 人数范围 | 12-15人 |
| 游戏锁定时机 | 有发言/投票记录后锁定 |

### 2. 主界面布局

两列布局：
- **左列**：固定显示 1-6 号玩家
- **右列**：动态渲染 7-N 号玩家（N为当前人数）

```
12人布局：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │  12  │
└──────┘          └──────┘
                   [+]    ← 加号按钮（小于15人时显示）

15人布局（满员）：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │ 12   │
└──────┘          │ 13[-]│ ← 减号在卡片内
                   │ 14[-]│
                   │ 15[-]│
                   └──────┘
                   （无加号，已达上限）
```

### 3. 增减按钮逻辑

**加号按钮（+）：**
- 位置：右列最下方
- 显示条件：当前人数 < 15 且游戏未开始
- 点击效果：增加一个新玩家（号码为当前最大号码+1）

**减号按钮（-）：**
- 位置：13/14/15 号玩家卡片内（右下角）
- 显示条件：玩家号码 >= 13 且游戏未开始
- 点击效果：移除该玩家，号码保持不变

### 4. 删除逻辑说明

删除玩家时号码不变：
- 当前有13、14、15号，删除13号后保留14、15号
- 不会被重新编号

## 二、发言模板功能

### 1. 模板显示规则

模板按钮按版型包含的角色动态显示/隐藏：
- 版型有预言家 → 显示预言家类模板
- 版型有女巫 → 显示女巫类模板
- 通用类模板始终显示

### 2. 模板分类与版型关联

| 模板分类 | 模板按钮 | 显示条件 |
|---------|---------|---------|
| 预言家类 | 跳预言家、查验X号、警徽流 | 版型含预言家 |
| 通灵师类 | 跳通灵师 | 版型含通灵师 |
| 女巫类 | 跳女巫、银水X号、毒X号 | 版型含女巫 |
| 守卫类 | 跳守卫、盾X号 | 版型含守卫 |
| 猎人类 | 跳猎人 | 版型含猎人 |
| 骑士类 | 跳骑士 | 版型含骑士 |
| 白痴类 | 跳白痴 | 版型含白痴 |
| 狼王类 | 跳狼王 | 版型含狼王 |
| 狼美人类 | 跳狼美人 | 版型含狼美人 |
| 机械狼类 | 跳机械狼 | 版型含机械狼 |
| 通用类 | 跳平民、保X号、踩X号、狼在X号 | 始终显示 |

### 3. 弹窗布局设计

发言弹窗内模板按钮采用网格布局，按角色类别分组：

## 三、玩家卡片快捷入口

### 1. 铅笔图标

玩家卡片右上角显示铅笔图标：
- 点击直接弹出角色选择弹窗（按版型角色分组）
- 无需经过菜单

```
┌───────────┐
│  ┌───┐ 📝 │ ← 铅笔图标，点击直接标记身份
│  │ 3 │    │
│  └───┘    │
│  预言     │ ← 已标记角色显示
└───────────┘
```

### 2. 点击卡片菜单

点击玩家卡片弹出选项菜单：
- 记录发言
- 查看投票
- 标记身份
- 清除身份标记（有标记时显示）

### 3. 长按卡片

切换玩家出局/存活状态。
