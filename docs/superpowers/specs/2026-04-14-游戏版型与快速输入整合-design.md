# 游戏版型与快速输入整合设计

## 概述

整合游戏版型选择功能与快速输入优化功能，实现：
- 版型决定可标记角色与发言模板
- 动态玩家布局（12-15人）
- 发言模板快速输入
- 玩家卡片快捷入口

---

## 一、人数选择与动态布局

### 1. 人数选择流程

人数选择已移至SetupActivity，简化MainActivity界面：
- 用户在SetupActivity先选择游戏人数（12-15人）
- 再选择游戏版型
- 进入MainActivity后人数已确定

**SetupActivity人数选择UI：**
- 4个按钮均分屏幕宽度（使用layout_weight）
- 选中状态：亮青色背景(teal_200) + 黑色文字 + 无边框
- 未选中状态：深色背景(info_panel) + 灰色文字 + 边框

```
┌───────────────────────────────────────┐
│  [12人]  [13人]  [14人]  [15人]       │  ← 均分宽度
│   选中    未选中   未选中   未选中      │  ← 选中高亮
└───────────────────────────────────────┘
```

### 2. 基础规则

| 维度 | 规则 |
|------|------|
| 默认人数 | 12人 |
| 人数范围 | 12-15人 |
| 选择时机 | SetupActivity选择版型前 |
| 传递方式 | Intent传递给MainActivity |

### 3. 主界面布局

两列布局（人数已确定，无需加减按钮）：
- **左列**：固定显示 1-6 号玩家
- **右列**：动态渲染 7-N 号玩家（N为选定人数）

```
12人布局：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │  12  │
└──────┘          └──────┘

15人布局：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │ 12   │
└──────┘          │ 13   │
                   │ 14   │
                   │ 15   │
                   └──────┘
```

**注意：** 加减按钮已移除，人数在SetupActivity一次性选择确定。

## 二、发言模板功能

### 1. 模板显示规则

模板按钮按版型包含的角色动态显示/隐藏：
- 版型有预言家 → 显示预言家类模板
- 版型有女巫 → 显示女巫类模板
- 通用类模板始终显示

### 2. 模板分类与版型关联

| 模板分类 | 模板按钮 | 显示条件 |
|---------|---------|---------|
| 预言家类 | 跳预言家、查验X号、警徽流 | 版型含预言家 |
| 通灵师类 | 跳通灵师 | 版型含通灵师 |
| 女巫类 | 跳女巫、银水X号、毒X号 | 版型含女巫 |
| 守卫类 | 跳守卫、盾X号 | 版型含守卫 |
| 猎人类 | 跳猎人 | 版型含猎人 |
| 骑士类 | 跳骑士 | 版型含骑士 |
| 白痴类 | 跳白痴 | 版型含白痴 |
| 狼王类 | 跳狼王 | 版型含狼王 |
| 狼美人类 | 跳狼美人 | 版型含狼美人 |
| 机械狼类 | 跳机械狼 | 版型含机械狼 |
| 通用类 | 跳平民、保X号、踩X号、狼在X号 | 始终显示 |

### 3. 弹窗布局设计

发言弹窗内模板按钮采用网格布局，按角色类别分组：

## 三、玩家卡片快捷入口

### 1. 铅笔图标

玩家卡片右上角显示铅笔图标：
- 点击直接弹出角色选择弹窗（按版型角色分组）
- 无需经过菜单

```
┌───────────┐
│  ┌───┐ 📝 │ ← 铅笔图标，点击直接标记身份
│  │ 3 │    │
│  └───┘    │
│  预言     │ ← 已标记角色显示
└───────────┘
```

### 2. 点击卡片菜单

点击玩家卡片弹出选项菜单：
- 记录发言
- 查看投票
- 标记身份
- 清除身份标记（有标记时显示）

### 3. 长按卡片

切换玩家出局/存活状态。

## 六、验收标准

**人数选择功能（SetupActivity）：**
- 4个按钮均分屏幕宽度
- 选中效果对比明显（亮青色背景+黑色文字）
- 未选中效果（深色背景+灰色文字+边框）
- 选择人数后传递给MainActivity

**动态布局功能：**
- 根据选择人数初始化玩家列表
- 左列固定1-6号，右列动态7-N号
- 无加减按钮干扰界面

**发言模板功能：**
- 模板按钮按版型角色显示/隐藏
- 通用类模板始终显示
- 点击模板弹出正确的二级弹窗或直接插入
- 二级弹窗号码动态显示当前玩家列表
- 多选功能正常工作
- 文字正确追加到输入框

**玩家卡片功能：**
- 铅笔图标点击直接弹出角色选择
- 点击卡片菜单选项正确
- 长按切换出局状态
- 已标记玩家显示正确边框颜色和角色角标

**角色选择弹窗：**
- 只显示版型包含的角色
- 分好人/狼人阵营两组
- 点击选中并关闭
