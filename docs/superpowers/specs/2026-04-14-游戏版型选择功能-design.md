# 游戏版型选择功能设计

## 概述

在游戏开始前添加版型选择流程，版型决定可标记的角色类型，人数仍可在主界面独立调整（12-15人）。

---

## 一、功能流程

```
APP启动 → SetupActivity（选择版型） → MainActivity → 游戏进行
                          ↓
                    版型数据传递给GameViewModel
                          ↓
                    角色弹窗/模板按钮均基于版型显示
```

---

## 二、预置版型配置

### 版型列表

| 版型名称 | 好人阵营 | 狼人阵营 | 默认人数 |
|---------|---------|---------|---------|
| 狼王守卫 | 预言家、女巫、守卫、猎人、4平民 | 3狼人、狼王 | 12人 |
| 预女猎白 | 预言家、女巫、猎人、白痴、4平民 | 4狼人 | 12人 |
| 狼美骑士 | 预言家、女巫、守卫、骑士、4平民 | 3狼人、狼美人 | 12人 |
| 通灵师机械狼 | 通灵师、女巫、猎人、守卫、4平民 | 3狼人、机械狼 | 12人 |

### 角色介绍（参考信息）

**狼王守卫版型：**
- 狼王：被公投出局可带走一人，被毒杀时不能开枪

**预女猎白版型：**
- 白痴：被投票出局后可继续发言，无其他功能

**狼美骑士版型：**
- 狼美人：每晚可连接一名玩家，死后殉情出局，不能连续两晚链接同一人
- 骑士：白天投票前可翻牌决斗，决斗狼人则狼人出局进入黑夜，决斗好人则骑士出局

**通灵师机械狼版型：**
- 通灵师（魔镜少女）：可查验玩家具体身份，机械狼未学习时被查验为机械狼，学习后查验为学习到的身份
- 机械狼（觉醒隐狼）：可学习一名玩家身份及技能，获得对应加强版技能，不能自爆，不参与狼队夜间交流

## 三、核心参数

| 维度 | 范围 | 调整位置 | 锁定时机 |
|------|------|----------|----------|
| 版型 | 预置4种 | SetupActivity | 选择后锁定 |
| 人数 | 12-15人 | MainActivity（加减按钮） | 游戏开始后锁定 |

## 四、数据结构

### GameSetup.kt（新增）

```kotlin
data class GameSetup(
    val name: String,              // 版型名称，如"狼王守卫"
    val goodRoles: List<SetupRole>, // 好人阵营角色
    val evilRoles: List<SetupRole>  // 狼人阵营角色
)

data class SetupRole(
    val role: Player.MarkedRole,   // 对应枚举值
    val count: Int,                // 数量
    val description: String? = null // 角色介绍（可选）
)

// 预置版型常量
object GameSetupPresets {
    val WOLF_KING_GUARD = GameSetup(
        name = "狼王守卫",
        goodRoles = listOf(
            SetupRole(Player.MarkedRole.SEER, 1),
            SetupRole(Player.MarkedRole.WITCH, 1),
            SetupRole(Player.MarkedRole.GUARD, 1),
            SetupRole(Player.MarkedRole.HUNTER, 1),
            SetupRole(Player.MarkedRole.VILLAGER, 4)
        ),
        evilRoles = listOf(
            SetupRole(Player.MarkedRole.WEREWOLF, 3),
            SetupRole(Player.MarkedRole.WOLF_KING, 1)
        )
    )
    // ... 其他3种版型
    val ALL = listOf(WOLF_KING_GUARD, SEER_WITCH_HUNTER_IDIOT, WOLF_BEAUTY_KNIGHT, SEER_MIRROR_MECH_WOLF)
}
```

### Player.MarkedRole枚举调整

新增角色以匹配版型：

```kotlin
enum class MarkedRole {
    NONE,
    // 好人阵营
    SEER,           // 预言家
    SEER_MIRROR,    // 通灵师（新增）
    WITCH,          // 女巫
    HUNTER,         // 猎人
    GUARD,          // 守卫
    KNIGHT,         // 骑士
    IDIOT,          // 白痴（新增）
    VILLAGER,       // 平民
    GOOD,           // 好人（泛指）
    // 狼人阵营
    WEREWOLF,       // 狼人
    WOLF_KING,      // 狼王（新增）
    WOLF_BEAUTY,    // 狼美人
    MECHANICAL_WOLF // 机械狼
}
```

### 交互逻辑

| 选项 | 行为 |
|------|------|
| 重新选择版型 | 清空记录 + 跳转到SetupActivity |
| 继续使用当前版型 | 清空记录 + 保持当前版型 + 恢复默认12人 |
| 取消 | 关闭弹窗 |

## 九、人数调整逻辑调整

原人数范围 8-15人 改为 **12-15人**：
- 默认12人
- 加号按钮：12-14人时显示，点击增加1人
- 减号按钮：仅13/14/15号玩家卡片内显示，点击移除该玩家
- 游戏开始后锁定人数

## 十一、验收标准

**版型选择：**
- APP启动进入SetupActivity
- 显示4种预置版型卡片，每个卡片显示名称和角色摘要
- 点击版型卡片跳转到MainActivity
- 版型数据正确传递到GameViewModel

**角色标记：**
- 角色选择弹窗只显示当前版型包含的角色
- 按好人阵营/狼人阵营分组显示
- 标记后卡片显示正确（边框颜色、角色角标）

**发言模板：**
- 模板按钮根据版型角色显示/隐藏
- 通用类模板始终显示
- 点击模板按钮功能正常

**人数调整：**
- 默认12人，范围12-15人
- 加号按钮在12-14人时显示
- 减号按钮仅在13/14/15号卡片内显示
- 游戏开始后锁定人数

**重置游戏：**
- 重置弹窗显示三选项
- "重新选择版型"跳转到SetupActivity
- "继续使用当前版型"清空记录保持版型
- "取消"关闭弹窗
