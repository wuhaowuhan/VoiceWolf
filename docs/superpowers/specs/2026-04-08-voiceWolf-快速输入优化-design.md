# VoiceWolf 快速输入优化设计

## 概述

优化VoiceWolf的发言记录和身份标记功能，增加快速输入模板，提升面杀记录效率。

## 功能范围

| 功能 | 状态 |
|------|------|
| 玩家人数动态调整 | 新增 |
| 发言模板快速输入 | 新增 |
| 身份标记快捷入口 | 优化 |
| 身份标记可视化 | 优化 |
| 投票记录 | 保持现状 |

## 一、玩家人数动态调整

### 1. 基础规则

- **默认人数**：12人
- **人数范围**：8-15人
- **游戏开始后**：号码固定，不可增减

### 2. 主界面布局

两列布局，动态显示：
- **左列**：1-6号玩家
- **右列**：7-N号玩家（N为当前人数）

```
12人布局：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │  12  │
└──────┘          └──────┘
                   [+]    ← 加号按钮（小于15人时显示）

13人布局：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │  12  │
└──────┘          │ 13[-]│ ← 新增玩家带减号
                   └──────┘
                   [+]    ← 加号按钮（小于15人时显示）

15人布局（满员）：
┌──────┐          ┌──────┐
│  1   │          │  7   │
│  2   │          │  8   │
│  3   │          │  9   │
│  4   │          │  10  │
│  5   │          │  11  │
│  6   │          │  12  │
└──────┘          │ 13[-]│
                   │ 14[-]│
                   │ 15[-]│
                   └──────┘
                   （无加号，已达上限）
```

### 3. 增减按钮逻辑

**加号按钮（+）：**
- 位置：右列最下方（12号下方）
- 显示条件：当前人数 < 15
- 点击效果：增加一个新玩家（号码为当前人数+1）

**减号按钮（-）：**
- 位置：新增玩家卡片内（13/14/15号的卡片内）
- 显示条件：当前人数 >= 13
- 点击效果：移除该玩家，但号码不变

### 4. 删除逻辑说明

删除玩家时**号码不变**：
- 当前13、14、15号，删除13号后场上保留14、15号
- 不会被重新编号为12、13号

```
删除13号：
原: 1-13号 → 删除后: 1-12号, 14号, 15号（共13人）

删除14号：
原: 1-13号, 14号, 15号 → 删除后: 1-13号, 15号（共14人）
```

### 5. 游戏状态控制

- **游戏未开始**：可自由增减玩家
- **游戏已开始**（有发言/投票记录）：增减按钮隐藏，人数锁定
- **重置游戏**：恢复默认12人，可重新增减

**预言家类：**
- 跳预言家（直接插入）
- 查验X号（号码单选 + 好人/狼人）
- 警徽流X号（多个号码）

**女巫类：**
- 跳女巫（直接插入）
- 银水X号（号码单选）
- 毒X号（号码单选）

## 四、数据流

### 1. 玩家人数调整流程

1. 用户点击加号按钮（游戏未开始时）
2. 新玩家添加，号码为当前最大号码+1
3. 右列布局动态更新显示新玩家卡片

### 2. 发言记录流程

1. 用户点击玩家或底部"发言"按钮
2. 打开发言弹窗
3. 用户点击模板按钮
   - 直接插入类：文字追加到输入框
   - 需选号码类：弹出二级弹窗，选择后文字追加
4. 用户可在输入框继续编辑
5. 点击保存，记录存储到ViewModel

### 3. 身份标记流程

1. 用户点击玩家卡片铅笔图标或"标记身份"菜单
2. 弹出角色选择弹窗（分组显示）
3. 用户点击角色按钮
4. 角色保存到ViewModel，玩家卡片更新显示

## 六、验收标准

**玩家人数功能：**
- 默认12人，可通过加号增加至15人
- 加号按钮仅在人数<15且游戏未开始时显示
- 减号按钮仅在13/14/15号玩家卡片内且游戏未开始时显示
- 删除玩家后号码不变（删除13号，14/15号仍保留）
- 游戏开始后增减按钮隐藏，人数锁定
- 重置游戏恢复默认12人

**发言模板功能：**
- 点击模板按钮能正确弹出二级弹窗或直接插入文字
- 二级弹窗号码选择、身份选择功能正常
- 多选号码类支持选多个号码并正确显示
- 玩家卡片快捷入口能预填充玩家号码

**身份标记功能：**
- 铅笔图标点击能直接弹出角色选择
- 角色选择弹窗分组显示正常
- 已标记玩家卡片边框颜色正确显示（好人绿、狼人红）
- 已出局玩家显示灰色遮罩
