# VoiceWolf 快速输入优化设计

## 概述

优化VoiceWolf的发言记录和身份标记功能，增加快速输入模板，提升面杀记录效率。

## 功能范围

| 功能 | 状态 |
|------|------|
| 发言模板快速输入 | 新增 |
| 身份标记快捷入口 | 优化 |
| 身份标记可视化 | 优化 |
| 投票记录 | 保持现状 |

---

## 一、发言模板功能

### 1. 模板短语列表

**预言家类：**
- 跳预言家（直接插入）
- 查验X号（号码单选 + 好人/狼人）
- 警徽流X号（多个号码）

**女巫类：**
- 跳女巫（直接插入）
- 银水X号（号码单选）
- 毒X号（号码单选）

**守卫类：**
- 跳守卫（直接插入）
- 盾X号（号码单选）

**通用类：**
- 保X号（多个号码）
- 踩X号（多个号码）
- 觉得狼在X号（多个号码）

## 三、数据流

### 发言记录流程

1. 用户点击玩家或底部"发言"按钮
2. 打开发言弹窗
3. 用户点击模板按钮
   - 直接插入类：文字追加到输入框
   - 需选号码类：弹出二级弹窗，选择后文字追加
4. 用户可在输入框继续编辑
5. 点击保存，记录存储到ViewModel

### 身份标记流程

1. 用户点击玩家卡片铅笔图标或"标记身份"菜单
2. 弹出角色选择弹窗（分组显示）
3. 用户点击角色按钮
4. 角色保存到ViewModel，玩家卡片更新显示

- 玩家卡片快捷入口能预填充玩家号码
- 铅笔图标点击能直接弹出角色选择

- 已标记玩家卡片边框颜色正确显示（好人绿、狼人红）
- 已出局玩家显示灰色遮罩
