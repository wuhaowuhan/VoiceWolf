# 狼王守卫版型
## 版型角色：
好人阵营：四平民、预言家、女巫、守卫、猎人
狼人阵营：三狼人、狼王（黑狼王）
## 角色介绍
狼王：也就是狼枪，如果被公投出局可以带走场上一名玩家，但是被毒杀时不能开枪带人

# 预女猎白
好人：预言家、女巫、猎人、白痴（白神），四平民
狼人：四狼人
## 角色介绍
白痴：被投票出局后 还可以发言，但是没有其他功能

# 狼美骑士
## 版型角色：
好人阵营：四平民、预言家、女巫、守卫、骑士
狼人阵营：三狼人、狼美人
## 角色介绍
狼美人：每天晚上可以连接一名玩家，死后被连接的玩家殉情出局，但是不能连续两晚链接同一名玩家
骑士:可以在白天投票前的任何时间内翻牌指定一名玩家进行决斗（一次性技能）。如被决斗的玩家是狼人，则此狼人玩家立即出局且游戏进入黑夜，如被决斗的玩家是好人，则骑士以死谢罪并发表“背锅侠”获奖感言，之后游戏按照决斗前的流程继续（在决斗期间发言的玩家其发言时长重置）。


# 通灵师机械狼：
## 版型角色：
好人阵营：通灵师【魔镜少女】、女巫、猎人、守卫，四平民
狼人阵营：机械狼【觉醒隐狼】、三狼人
## 角色介绍
- 通灵师【魔镜少女】拥有主动技能“冥想”，可以查验一名场上玩家的具体身份，可以将他看作为神职阵营的“石像鬼”，或者弱化版的“纯白之女”，与“纯白之女”不同的是“通灵师”不能将狼人查验出局。当“机械狼”在未学习状态时被“通灵师”查验为“机械狼”（法官手势为双手狼爪），当“机械狼”进行学习后，“通灵师”只能查验到其“学习到的身份”（划重点）。魔镜少女（机械狼）不能重复验同一名玩家。
- 机械狼【觉醒隐狼】可在任意一夜开启“学习”状态，即选择学习场上一名玩家的身份（划重点）及技能：如学到“守卫”，那可得到加强版“守护”技能，可抵挡狼刀、女巫的毒药和猎人夜间的子弹；如学习到“女巫”，可得到一瓶“毒药”；学习到“猎人”，出局后可发动“开枪”（开枪规则同猎人）；学习到“通灵师”，可以查验一个人的真实身份；学习到“狼人”，可以多一次刀，但仅可以在其他狼人出局“机械狼”带刀时使用；学习到“平民”就只能当一个普通的村民，相当于“隐狼”。
## 特别说明
1、关于重复验人：“通灵师”不能重复验人。

2、关于自爆：“机械狼”不能自爆，且全程不参与狼队夜间交流。

3、关于机械盾和奶穿：“机械狼”的“机械盾”可以抵挡“女巫”的“毒药”和“猎人”的“夜间子弹”；“机械狼”的“机械盾”如和“女巫”的“解药”作用于同一名玩家，该玩家会被奶穿（出局）；“机械狼”的“机械盾”和“守卫”的“守护”共同作为于同一名玩家 ，该玩家不会被奶穿；被奶穿的猎人（或“机械猎”）可以开枪。

4、关于学习技能使用：“机械狼”学习到的技能可在学习当夜之后的任意一夜（一日）中使用，其中“机械毒”、“机械盾”和“机械枪”（规则同猎人）仅可生效一次，“机械冥想”使用和生效次数无限制。

5、关于额外刀：守卫的“守护”可以抵挡“机械狼”的“额外刀”（与“狼鸦之爪”不同），但如果“狼刀”和“额外刀”作用的目标是同一个，则该目标必死。

6、关于神职技能：被学习技能的神职本身技能依旧保留（与“蚀日侍女”不同）。

7、关于出局翻牌：出局翻枪不翻牌，需自行判断是“猎人”还是“机械猎”。

8、关于夜间的子弹：在线下狼人杀对决中，为了保证猎人吃刀后开枪时的公正性和避免场外因素，因此“猎人”和“机械猎”夜间吃刀的开枪都在当天夜间环节进行结算，这就是“夜间的子弹”。在版型中，“机械盾”可抵挡当夜死亡猎人的“子弹”，但如果猎人白天被投出局开枪，“机械盾”无法抵挡。
注意：在【镜隐迷踪】版型当中，机械盾可以挡住狼刀和女巫毒，但不能抵挡猎人的子弹，因此被刀死的猎人是白天开枪，没有夜间的子弹一说。

9、关于结算：胜负的结算顺序为 狼刀>女巫毒>机械（毒/刀）。
